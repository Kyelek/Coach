# Mi Coach

App web (PWA) para el móvil: rutina diaria, entreno con el peso corporal, menú semanal barato, dejar de fumar y buscar trabajo. La IA es Google Gemini con clave gratuita.

## Clave gratuita de IA
1. Entra en https://aistudio.google.com/apikey con tu cuenta de Google.
2. Pulsa "Create API key" y cópiala.
3. Pégala en la app (en la bienvenida o en ⚙️ Ajustes).

La clave y todos tus datos se guardan solo en tu móvil.

## Probar en el ordenador
```
python -m http.server 8000
```
y abre http://localhost:8000

## Instalar en el móvil
Para instalarla, la app tiene que estar publicada en una web con HTTPS (Vercel, Netlify o GitHub Pages son gratis: basta con subir esta carpeta tal cual).
- Android (Chrome): menú ⋮ → "Instalar aplicación" / "Añadir a pantalla de inicio".
- iPhone (Safari): botón Compartir → "Añadir a pantalla de inicio".

## Copia de seguridad
⚙️ Ajustes → "Exportar copia" descarga tus datos. Con "Importar" los recuperas en otro móvil.
